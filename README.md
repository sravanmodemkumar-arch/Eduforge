# Eduforge

An open-source educational platform for creating, managing, and delivering interactive learning experiences.

## Features

- Course creation and management
- Interactive lesson builder
- Student progress tracking
- Quiz and assessment engine
- Discussion forums

## Getting Started

### Prerequisites

- Python 3.10+
- pip

### Installation

```bash
# Clone the repository
git clone https://github.com/sravanmodemkumar-arch/Eduforge.git
cd Eduforge

# Create a virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the application
python -m eduforge
```
